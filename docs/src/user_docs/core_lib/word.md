# Word procedures

Module `miden::core::word` contains utilities for manipulating _words_ &mdash; sequences of four _field elements_.
See [Terms and notations](./index.md#terms-and-notations) for more information.

Procedure signatures, cycle counts, and detailed stack notes are generated from the MASM comments and kept in sync by CI:

- [`crates/lib/core/docs/word.md`](https://github.com/0xMiden/miden-vm/blob/next/crates/lib/core/docs/word.md)
