
## miden::core::precompiles::hashes::sha256
| Procedure | Description |
| ----------- | ------------- |
| hash_bytes_mem | Hashes a variable-length byte message using the deferred SHA-256 precompile.<br /><br />Input:  [in_ptr, len_bytes, out_ptr, ...]<br />Output: [...] (eight packed little-endian u32 digest limbs written to out_ptr)<br /><br />Both pointers must be word-aligned. Input memory holds bytes packed little-endian into u32<br />limbs; unused bytes and felts in the final 32-byte chunk must be zero. The message length must<br />fit the configured max_hash_len_bytes execution limit. Input and output memory may overlap.<br />Advice is untrusted: the output chunk is bound by the logged SHA-256 assertion.<br /> |
