
## miden::core::mem
| Procedure | Description |
| ----------- | ------------- |
| memcopy_words | Copies `n` words from `read_ptr` to `write_ptr`.<br /><br />`read_ptr` and `write_ptr` pointers *must be* word-aligned.<br /><br />Inputs:  [n, read_ptr, write_ptr]<br />Outputs: []<br /><br />Where:<br />- n is the number of words which should be copied.<br />- read_ptr is the memory pointer where the words to copy are stored.<br />- write_ptr is the memory pointer where the words will be copied.<br /><br /># Panics<br /><br />Panics if the source range `[read_ptr, read_ptr + 4*n)` and destination range<br />`[write_ptr, write_ptr + 4*n)` overlap.<br /><br />Total cycles: 15 + 16 * num_words<br /> |
| memcopy_elements | Copies `n` elements from `read_ptr` to `write_ptr`.<br /><br />Inputs:  [n, read_ptr, write_ptr]<br />Outputs: []<br /><br />Where:<br />- n is the number of elements which should be copied.<br />- read_ptr is the memory pointer where the elements to copy are stored.<br />- write_ptr is the memory pointer where the elements will be copied.<br /><br /># Panics<br /><br />Panics if the source range `[read_ptr, read_ptr + n)` and destination range<br />`[write_ptr, write_ptr + n)` overlap.<br /><br />Total cycles: 7 + 14 * num_elements<br /> |
| pipe_double_words_to_memory | Copies an even number of words from the advice stack to memory, updating the Eidos state.<br /><br />Inputs:  [BLOCK_LO, BLOCK_HI, CV, write_ptr, end_ptr]<br />Outputs: [BLOCK_LO', BLOCK_HI', CV', write_ptr]<br /><br />Where:<br />- BLOCK_LO is the first preserved block word (positions 0-3, on top of stack).<br />- BLOCK_HI is the second preserved block word (positions 4-7).<br />- CV is the current chaining word (positions 8-11).<br />- write_ptr is the memory pointer where the words will be copied.<br />- end_ptr is the memory pointer where the copying should end.<br /><br />Notice that the `end_ptr - write_ptr` value must be positive and a multiple of 8.<br /><br /> |
| pipe_words_to_memory | Copies an arbitrary number of words from the advice stack to memory, updating the Eidos state.<br /><br />Inputs:  [num_words, write_ptr]<br />Outputs: [BLOCK_LO, BLOCK_HI, CV, write_ptr']<br /><br />Where:<br />- num_words is the number of words which will be copied to the memory.<br />- write_ptr is the memory pointer where the words will be copied.<br />- write_ptr' is the memory pointer to the end of the copied words.<br />- BLOCK_LO and BLOCK_HI are the final preserved block words; CV is the final digest.<br /><br /> |
| pipe_words_to_memory_in_domain | Copies advice words to memory while computing their domain-tagged hash.<br /><br />Inputs:  [domain, num_words, write_ptr]<br />Outputs: [DIGEST, write_ptr']<br /><br />Where:<br />- domain identifies the Eidos hash domain.<br />- num_words is the number of words copied from the advice stack.<br />- write_ptr is the word-aligned destination address.<br />- write_ptr' points immediately after the copied words.<br />- DIGEST matches `Eidos::hash_elements_in_domain` over the copied felts.<br /> |
| pipe_preimage_to_memory | Moves an arbitrary number of words from the advice stack to memory and asserts it matches the<br />commitment.<br /><br />Inputs:  [num_words, write_ptr, COMMITMENT]<br />Outputs: [write_ptr']<br /><br />Where:<br />- num_words is the number of words which will be copied to the memory.<br />- write_ptr is the memory pointer where the words will be copied.<br />- write_ptr' is the memory pointer to the end of the copied words.<br />- COMMITMENT is the commitment that the one calculated during this procedure will be compared<br />with.<br /><br /> |
| pipe_double_words_preimage_to_memory | Moves an even number of words from the advice stack to memory and asserts that their Eidos<br />compression-chain hash matches a given commitment.<br /><br />Inputs:  [num_words, write_ptr, COMMITMENT]<br />Outputs: [write_ptr']<br /><br />Where:<br />- num_words is the number of words which will be copied to the memory.<br />- write_ptr is the memory pointer where the words will be copied.<br />- write_ptr' is the memory pointer to the end of the copied words.<br />- COMMITMENT is the commitment that the one calculated during this procedure will be compared<br />with.<br /> |
| pipe_double_words_preimage_to_memory_with_domain | Moves an even number of words from the advice stack to memory and asserts that their<br />domain-tagged Eidos compression-chain hash matches a given commitment.<br /><br />Like `pipe_double_words_preimage_to_memory`, but binds a domain identifier into the Eidos CV.<br /><br />Inputs:  [domain, num_words, write_ptr, COMMITMENT]<br />Outputs: [write_ptr']<br /><br />Where:<br />- domain is the domain identifier included in the Eidos chaining word.<br />- num_words is the number of words which will be copied to the memory (must be even).<br />- write_ptr is the memory pointer where the words will be copied.<br />- write_ptr' is the memory pointer to the end of the copied words.<br />- COMMITMENT is the domain-tagged digest that the preimage must hash to.<br /><br /> |
