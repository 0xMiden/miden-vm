
## miden::core::pcs::fri::frie2f4
| Procedure | Description |
| ----------- | ------------- |
| verify_query_layer | Authenticates one opened FRI row, checks the incoming value against its selected element,<br />and folds the row to the next layer with fri_ext2fold4. Advances layer_ptr by eight felts.<br /><br />Input:  [layer_ptr, layer_ptr, poe, p, e0, e1, layer_ptr, rem_ptr, x, x, x, x, x, x, x, x, ...]<br />Output: [is_not_last_layer, layer_ptr+8, layer_ptr+8, poe^4, f_pos, ne0, ne1, layer_ptr+8, rem_ptr, x, x, x, x, x, x, x, x, ...]<br /> |
| verify_query_half | Verifies a query through all FRI layers, then checks it against a remainder containing<br />REMAINDER_MAX_COEFFICIENTS / 2 extension coefficients.<br /><br />Input:  [poe, p, e0, e1, layer_ptr, rem_ptr, ...]<br />Output: [scratch(12), ...]<br /><br />Here poe = g^p for the initial domain generator g, and (e0, e1) is the initial-layer value at p.<br />Word-aligned layer records occupy [layer_ptr, rem_ptr) in eight-felt steps; equal pointers mean<br />no layers. The remainder at rem_ptr contains extension coefficients in descending degree order.<br /><br />TMP1_PTR must hold [rem_ptr, TMP2_PTR, 0, 0]. TMP2_PTR is overwritten with the evaluation<br />point. Neither scratch word may overlap the remainder.<br /> |
| verify_query_max | Uses `verify_query_half`'s contract with the maximum-length remainder.<br /> |
| verify | Verifies a FRI proof where the proof was generated over the quadratic extension of the base<br />field and layer folding was performed using folding factor 4.<br /><br />Query records [g^p, p, e0, e1] occupy a nonempty word-aligned range from the address stored<br />in FRI_QUERIES_ADDRESS_PTR to FRI_COM_PTR. Here g is the initial LDE domain generator.<br />Eight-felt layer records follow, ending at the address stored in REMAINDER_POLY_ADDRESS_PTR;<br />each stored domain size and tree depth must fit u32. The remainder contains descending-degree<br />extension coefficients. REMAINDER_POLY_SIZE_PTR must hold REMAINDER_MAX_COEFFICIENTS or half<br />that count, matching the stored coefficients.<br /><br />Initializes TMP1_PTR for Horner evaluation and overwrites FRI_VERIFY_STATE_PTR and TMP2_PTR.<br />These scratch words must not overlap the query, layer or coefficient regions.<br /><br />Input:  [...]<br />Output: [...]<br /> |
