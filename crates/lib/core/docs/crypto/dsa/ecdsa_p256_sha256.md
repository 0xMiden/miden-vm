
## miden::core::crypto::dsa::ecdsa_p256_sha256
| Procedure | Description |
| ----------- | ------------- |
| verify | Verifies a P-256 ECDSA witness over the SHA-256 hash of a Word message, encoded in the native<br />limb ABI below.<br /><br />Conventions: MSG_WORD is hashed as its 32 little-endian bytes; the message scalar z is the<br />SHA-256 digest read as a big-endian integer and reduced modulo n; PK_COMM is<br />`Eidos::hash_elements(QX[8] \|\| QY[8])` over the little-endian u32 coordinate limbs. Acceptance<br />matches FIPS 186-5 and EIP-7951 ECDSA verification of the prehash SHA-256(message): high-s<br />witnesses are accepted.<br /><br />Inputs:<br />Operand stack: [PK_COMM, MSG_WORD, ...]<br />Advice stack:  [QX[8] \| QY[8] \| SIG_R[8] \| SIG_S[8] \| ...]<br />Outputs:<br />Operand stack: [...]<br />Advice stack:  [...]<br /><br />Where:<br />- `PK_COMM`: Eidos hash commitment of `QX[8] \|\| QY[8]`, where coordinates are native<br />little-endian numeric u32 limbs, one limb per Felt.<br />- `MSG_WORD`: single word / 4 felts representing the 32-byte message to verify.<br />- `QX[8]`, `QY[8]`: native public-key coordinates as little-endian u32 limbs.<br />- `SIG_R[8]`, `SIG_S[8]`: native signature scalars as little-endian u32 limbs.<br /><br />Local memory layout (element addresses):<br />- loc[0 ..16] : native public key, QX[8] \|\| QY[8].<br />- loc[16..24] : SHA-256 message/digest scratch buffer.<br /><br />No result word is pushed. The procedure traps on malformed native limbs, invalid/off-curve public<br />keys, invalid signature scalars, or failed signature verification.<br /><br />Low-s is intentionally not enforced: this procedure proves that some untrusted advice satisfies<br />the ECDSA equation, and `(r, s)` and `(r, n - s)` are equivalent witnesses. An adaptation that<br />verifies a committed signature must bind the exact signature encoding inside the VM. Low-s is a<br />separate canonicality policy and only needs to be enforced when the caller requires it.<br /><br />Advice is untrusted. This procedure binds QX/QY to `PK_COMM`, and validates the public key,<br />reduced SHA-256 prehash, and signature scalars through precompile-backed deferred evaluation.<br /><br />Invocation: exec<br /> |
| verify_bytes | Verifies a P-256 ECDSA witness over a variable-length message stored as bytes in memory.<br /><br />Inputs:<br />Operand stack: [PK_COMM, MSG_PTR, MSG_LEN_BYTES, ...]<br />Advice stack:  [QX[8] \| QY[8] \| SIG_R[8] \| SIG_S[8] \| ...]<br />Outputs:<br />Operand stack: [...]<br />Advice stack:  [...]<br /><br />Where:<br />- `PK_COMM`: Eidos hash commitment of `QX[8] \|\| QY[8]`, where coordinates are native<br />little-endian numeric u32 limbs, one limb per Felt.<br />- `MSG_PTR`: word-aligned address containing the message as packed little-endian u32 limbs.<br />- `MSG_LEN_BYTES`: number of message bytes to hash. Unused bytes in the final u32 and remaining felts<br />in the final 32-byte chunk must be zero.<br />- `QX[8]`, `QY[8]`: native public-key coordinates as little-endian u32 limbs.<br />- `SIG_R[8]`, `SIG_S[8]`: native signature scalars as little-endian u32 limbs.<br /><br />No result word is pushed. The procedure traps if:<br />- `MSG_PTR` is not word-aligned.<br />- `MSG_LEN_BYTES` exceeds the configured `max_hash_len_bytes` execution limit.<br />- a message-memory felt is not a valid u32.<br />- unused message bytes or felts in the final 32-byte chunk are nonzero.<br />- public-key or signature limbs are malformed, the public key is invalid/off-curve, the signature<br />scalars are invalid, or signature verification fails.<br /><br />Advice is untrusted. This procedure binds QX/QY to `PK_COMM`, hashes the specified memory range,<br />and validates the reduced SHA-256 prehash and signature scalars through precompile-backed<br />deferred evaluation.<br /><br />Invocation: exec<br /> |
| recover | Recovers the P-256 public key from a native recovery witness over a Word message.<br /><br />Inputs:<br />Operand stack: [MSG_WORD, SIG_PTR, ...]<br />Outputs:<br />Operand stack: [QX[8] \| QY[8], ...]<br /><br />Where:<br />- `MSG_WORD`: four felts split into eight little-endian u32 limbs and hashed exactly as by<br />`verify`.<br />- `SIG_PTR`: word-aligned address of caller-owned memory containing the native recovery<br />witness `R_LE_U32[8] \|\| S_LE_U32[8] \|\| V`. The memory must remain unchanged until the procedure<br />returns.<br />- `R_LE_U32[8]`, `S_LE_U32[8]`: signature scalars as little-endian u32 limbs.<br />- `V`: recovery byte 0 or 1, the y-parity of the recovery point R.<br />- `QX[8]`, `QY[8]`: recovered affine public-key coordinates as little-endian u32 limbs.<br /><br />Panics if:<br />- `SIG_PTR` is not word-aligned.<br />- a signature limb is not a u32, or `r` or `s` is zero or not a canonical P-256 scalar.<br />- `V` is not 0 or 1.<br />- candidate public-key advice or the derived recovery point is invalid or inconsistent with the<br />exact message, signature, and recovery byte.<br /><br />Exact `r`, `s`, and `v`, including high-s, are bound; low-s is a separate caller policy. A wrong<br />message can recover a different valid key; callers must authenticate the returned key against<br />trusted state.<br />Raw signature bytes are not a replay key because equivalent low-s and high-s encodings exist.<br /><br />Invocation: exec<br /> |
| recover_bytes | Recovers the P-256 public key from a native recovery witness over bytes in memory.<br /><br />Inputs:<br />Operand stack: [MSG_PTR, MSG_LEN_BYTES, SIG_PTR, ...]<br />Outputs:<br />Operand stack: [QX[8] \| QY[8], ...]<br /><br />Where:<br />- `MSG_PTR`: word-aligned address containing the message as packed little-endian u32 limbs.<br />- `MSG_LEN_BYTES`: number of message bytes to hash. Unused bytes in the final u32 and remaining<br />felts in the final 32-byte chunk must be zero.<br />- `SIG_PTR`: word-aligned address of caller-owned memory containing the native recovery<br />witness `R_LE_U32[8] \|\| S_LE_U32[8] \|\| V`. The memory must remain unchanged until the procedure<br />returns.<br />- `R_LE_U32[8]`, `S_LE_U32[8]`: signature scalars as little-endian u32 limbs.<br />- `V`: recovery byte 0 or 1, the y-parity of the recovery point R.<br />- `QX[8]`, `QY[8]`: recovered affine public-key coordinates as little-endian u32 limbs.<br /><br />Panics if:<br />- `MSG_PTR` or `SIG_PTR` is not word-aligned.<br />- `MSG_LEN_BYTES` exceeds the configured `max_hash_len_bytes` execution limit.<br />- a message-memory felt is not a u32, or final-chunk padding is nonzero.<br />- a signature limb is not a u32, or `r` or `s` is zero or not a canonical P-256 scalar.<br />- `V` is not 0 or 1.<br />- candidate public-key advice or the derived recovery point is invalid or inconsistent with the<br />exact message, signature, and recovery byte.<br /><br />Exact `r`, `s`, and `v`, including high-s, are bound; low-s is a separate caller policy. A wrong<br />message can recover a different valid key; callers must authenticate the returned key against<br />trusted state.<br /><br />Invocation: exec<br /> |
