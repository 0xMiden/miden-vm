
## miden::core::crypto::dsa::leansig_poseidon2
| Procedure | Description |
| ----------- | ------------- |
| verify | Verifies a Miden-native Poseidon2 LeanSig signature.<br /><br />This is a fixed-parameter generalized-XMSS verifier with lifetime 2^32, target-sum dimension 46,<br />base 8, target sum 200, and a 32-level authentication path. It follows the verification flow of<br />`leanEthereum/leanSig`, but uses Miden's native Goldilocks Poseidon2 permutation and is therefore<br />not wire-compatible with the reference KoalaBear Poseidon1 instantiation.<br /><br />Inputs:<br />Operand stack: [PK_COMM, MSG, EPOCH, ...]<br />Advice stack:  [ROOT: word \| PARAMETER: word \| RHO: word \|<br />SIG_HASHES: [word; 46] \| AUTH_PATH: [word; 32] \| ...]<br />Outputs:<br />Operand stack: [...]<br />Advice stack:  [...]<br /><br />`PK_COMM`, `MSG`, `ROOT`, `PARAMETER`, `RHO`, every signature hash, and every authentication<br />node are words. `EPOCH` must be a canonical u32. `PK_COMM` is Poseidon2::merge_in_domain(1,<br />ROOT, PARAMETER). The procedure traps on malformed inputs or failed verification.<br /><br />Local memory layout (element addresses):<br />loc[0 ..  4] : public-key root<br />loc[4 ..  8] : public hash parameter<br />loc[8 .. 12] : message<br />loc[12]      : epoch<br />loc[13]      : chain index, later reused for the current Merkle position<br />loc[14]      : codeword pointer, later reused for the current Merkle level<br />loc[15]      : endpoint write pointer<br />loc[16.. 20] : rho, later reused for the current Merkle node<br />loc[24.. 32] : message-hash rate output<br />loc[32.. 78] : target-sum codeword<br />loc[80..264] : 46 reconstructed Winternitz chain endpoints<br /> |
