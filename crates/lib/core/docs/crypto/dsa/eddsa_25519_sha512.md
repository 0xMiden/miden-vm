
## miden::core::crypto::dsa::eddsa_25519_sha512
| Procedure | Description |
| ----------- | ------------- |
| verify | Verifies an Ed25519 signature over the 32 little-endian bytes of a Word.<br /><br />Input:  [PK_COMM, MSG_WORD, ...]<br />Advice: [A[8] \| R[8] \| S[8] \| ...], packed little-endian u32 limbs of the RFC 8032 encodings.<br />Output: [...]<br /><br />PK_COMM is the Eidos commitment to the eight packed limbs of the compressed public key A,<br />matching miden-crypto's PublicKey::to_commitment. The procedure proves SHA-512(R \|\| A \|\| M)<br />and [s]B = R + [k]A with k reduced modulo l. It rejects noncanonical encodings/scalars,<br />small-order A or R, and invalid signatures. This is ordinary Ed25519, not Ed25519ph.<br />Its acceptance policy is stricter than miden-crypto's PublicKey::verify: MASM rejects<br />noncanonical encodings and small-order A/R, while that API uses dalek's non-strict verification.<br />The configured max_hash_len_bytes must be at least 96 for the R \|\| A \|\| M preimage.<br />The signature is an uncommitted advice witness; callers needing exact signature binding must<br />commit to its encoding separately. No result is pushed; failed verification traps.<br /> |
| verify_bytes | Verifies an Ed25519 signature over bytes in memory, using caller-owned scratch memory.<br /><br />Input:  [PK_COMM, MSG_PTR, MSG_LEN_BYTES, SCRATCH_PTR, ...]<br />Advice: [A[8] \| R[8] \| S[8] \| ...], packed little-endian u32 limbs.<br />Output: [...]<br /><br />MSG_PTR and SCRATCH_PTR must be word-aligned. The message is packed little-endian into u32<br />limbs, with zero unused bytes/felts in the last 32-byte chunk. Scratch must contain room for<br />16 + 8*max(1,ceil(MSG_LEN_BYTES/32)) felts and must not overlap the message. Its contents are<br />overwritten. Both complete ranges must lie below this procedure's local frame; parent-frame<br />locals are supported. MSG_LEN_BYTES + 64 must fit the max_hash_len_bytes execution limit.<br />Public-key commitments and acceptance rules are the same as verify. Advice is untrusted.<br /> |
