Encrypts a Felt message with the recipient's EcGFp5 public key.<br />The context is authenticated but not encrypted.<br /><br />For generator G, recipient point Q, and ephemeral scalar r, compute `R = rG` and `S = rQ`.<br />Extract a secret from S, R, and Q, then expand it with the context digest into the AEAD key<br />and nonce. Encrypt plaintext and authenticate the ciphertext together with the full context.<br /><br />Supply a fresh random scalar for each encryption through private advice. This module checks<br />its range but does not generate it. Keep the scalar, plaintext, and execution witness private;<br />witness privacy also requires zero-knowledge.<br /><br />Matches `miden_crypto::ies::ecgfp5_eidos`. Sender authentication and replay protection belong<br />to the application.<br />
