Encrypts a Felt message with the recipient's EcGFp5 public key.<br />The context is authenticated but not encrypted.<br /><br />For generator G, recipient point Q, and ephemeral scalar r, compute `R = rG` and `S = rQ`.<br />Extract a secret from S, R, and Q, then expand it with the context digest into the AEAD key<br />and nonce. Encrypt plaintext and authenticate the ciphertext together with the full context.<br /><br />The host supplies a fresh random scalar and agreement witnesses as private advice.<br />Keep the scalar, plaintext, and execution witness private, and use zero-knowledge proving.<br /><br />Matches `miden_crypto::ies::ecgfp5_eidos`. Sender authentication and replay protection belong<br />to the application.<br />
