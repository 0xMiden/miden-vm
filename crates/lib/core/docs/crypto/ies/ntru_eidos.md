Encrypts Felt messages with the recipient's NTRU public key.<br /><br />Encapsulation uses the recipient's public key and fresh randomness to produce a shared secret<br />and a capsule (KEM ciphertext). The shared secret, public-key commitment, context digest, and<br />capsule digest determine the AEAD key and nonce.<br />The context is also authenticated as associated data; it is not encrypted.<br /><br />The output envelope contains the capsule, encrypted message, and authentication tag.<br />The recipient uses its private key to recover the shared secret from the capsule and derive<br />the same key and nonce.<br />Decode the envelope with Rust's `ies::ntru_eidos::Envelope::from_elements` and open it with<br />`ies::ntru_eidos::open`, supplying the recipient's secret key and the same context.<br />
