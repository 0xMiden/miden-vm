EcGFp5 Diffie-Hellman key agreement.<br /><br />For generator G, recipient public key Q, and private scalar r, the agreement computes<br />the ephemeral point R = rG and shared point S = rQ.<br /><br />Keep the scalar, shared point, and advice private. Advice generation and execution are<br />variable-time and need a trusted environment; witness privacy also requires zero-knowledge.<br />Derive encryption keys from the shared point with a KDF.<br />


## miden::core::crypto::ecdh::ecgfp5
| Procedure | Description |
| ----------- | ------------- |
| agree | Computes the ephemeral point R = rG and shared point S = rQ, and returns the recipient point Q.<br /><br />Input:  [public_key(4), ...]<br />Advice: [Q(5), scalar and multiplication witnesses, ...]<br />Output: [R(5), S(5), Q(5), ...]<br /><br />`public_key` is the commitment returned by Rust's `PublicKey::to_commitment`.<br />Prepare the advice with `PublicKey::advise`.<br />The inner `call` isolates scratch memory from the caller.<br />Fails if Q does not match the commitment, Q is not a valid nonidentity point, the scalar is<br />zero or out of range, or a multiplication witness or output encoding is invalid.<br /><br />Invocation: exec<br /> |
| agree_preprocessed | Computes R = rG and S = rQ, and returns the recipient point Q from its preprocessed public key.<br /><br />Input:  [public_key(4), ...]<br />Output: [R(5), S(5), Q(5), ...]<br /><br />`public_key` is the commitment returned by Rust's `PreparedPublicKey::to_commitment`.<br />This procedure authenticates entries supplied through advice against that commitment.<br />It assumes the issuer generated the tables correctly.<br /><br />Prepare the advice with Rust's `PreparedPublicKey::advise`.<br />The inner `call` isolates scratch memory from the caller.<br />Fails if the scalar is zero or out of range, or a table opening, slope, or encoding is invalid.<br /><br />Invocation: exec<br /> |
