
## miden::core::crypto::aead_eidos::primitives
| Procedure | Description |
| ----------- | ------------- |
| derive_ctr_key | Derives the CTR chaining value (`K_CTR`) from a key and nonce.<br /><br />Input:  [key(4), nonce(4), ...]<br />Output: [K_CTR(4), ...]<br /><br />Invocation: exec<br /> |
| derive_mac_key | Derives the MAC key `[r0, r1, s0, s1]` from a key and nonce.<br />The pairs `r = (r0, r1)` and `s = (s0, s1)` are the evaluation point and final mask.<br /><br />Input:  [key(4), nonce(4), ...]<br />Output: [K_MAC(4), ...]<br /><br />Invocation: exec<br /> |
| encrypt_felts_expanded | Encrypts `num_felts` plaintext Felts into expanded ciphertext limbs.<br /><br />Input:  [K_CTR(4), src_ptr, dst_ptr, counter, num_felts, ...]<br />Output: [K_CTR(4), src_ptr + num_felts, dst_ptr + 2*num_felts,<br />counter + ceil(num_felts / 8), ...]<br /><br />The caller supplies disjoint, word-aligned u32 ranges below its local frame and a u32<br />counter span that does not overflow. Public encryption starts at zero; its message limit<br />keeps the counter span within u32.<br /><br />Clears any tail scratch on return. The returned counter may be 2^32 after its last block.<br /><br />Invocation: exec<br /> |
| auth_expanded_exact | Authenticates associated data and expanded ciphertext, using lengths in Felts.<br /><br />MAC input:<br />`nonce(4) \|\| AD(ad_len) \|\| ciphertext(ct_len) \|\| [ad_len, ct_len] \|\| zero_padding`<br /><br />Pad only the end of this stream to a multiple of eight Felts, not each segment separately.<br />Thus an odd-length segment pairs its last Felt with the next segment's first Felt.<br />The length pair distinguishes data from padding, including when the data ends in zeros.<br /><br />Pair adjacent Felts as quadratic-extension coefficients `c_0, ..., c_(m-1)`.<br />For evaluation point r and mask s from K_MAC:<br />`a_0 = 1`<br />`a_(i+1) = a_i*r + c_i`<br />`tag = a_m*r + s`<br /><br />Starting at one binds the coefficient count. The final multiplication makes every input<br />coefficient multiply a positive power of r.<br /><br />Input:  [K_MAC(4), nonce(4), ad_ptr, ad_len, ct_ptr, ct_len, ...]<br />Output: [tag0, tag1, ...]<br /><br />The caller checks word-aligned u32 pointers, u32 lengths, and non-empty ranges below its<br />local frame. The padded input must fit in 2^28 Felts. Ciphertext limbs must be u32 values;<br />encryption produces them, and decryption checks them by re-encrypting the plaintext witness.<br /><br />All locals are cleared on successful return; the mask is removed from the operand stack.<br />This does not erase the private execution trace.<br /><br />Invocation: exec<br /> |
| auth_empty_ad_expanded_exact | Authenticates `ct_len` expanded ciphertext Felts with empty associated data.<br /><br />Uses the MAC stream defined by `auth_expanded_exact` with `ad_len = 0`:<br />`nonce(4) \|\| ciphertext(ct_len) \|\| [0, ct_len] \|\| zero_padding`.<br /><br />Input:  [K_MAC(4), nonce(4), ct_ptr, ct_len, ...]<br />Output: [tag0, tag1, ...]<br /><br />Uses the same length and memory preconditions as auth_expanded_exact, with empty AD.<br />ct_len must be even: each plaintext Felt contributes two ciphertext limbs.<br /><br />Invocation: exec<br /> |
