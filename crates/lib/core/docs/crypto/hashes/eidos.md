
## miden::core::crypto::hashes::eidos
| Procedure | Description |
| ----------- | ------------- |
| init_chaining_word_with_params | Constructs an Eidos chaining word from a domain tag and three domain-defined<br />parameters. Every input must fit in a u32. Each occupies the low lane of one packed Felt; the<br />corresponding high lane is a fixed BLAKE3 IV word.<br /><br />Input:  [domain_tag, param0, param1, param2, ...]<br />Output: [CV, ...]<br /><br />Invocation: exec<br /> |
| empty_felt_sequence_digest | Returns the Eidos digest of an empty generic Felt sequence.<br /><br />Input:  [...]<br />Output: [DIGEST, ...]<br /><br />Invocation: exec<br /> |
| init_chaining_word | Constructs `Eidos::init_chaining_word(GENERIC_FELT_SEQUENCE, n)`.<br />`n` must fit in a u32.<br /><br />Input:  [n, ...]<br />Output: [CV, ...]<br /><br />Invocation: exec<br /> |
| init_chaining_word_in_domain | Constructs an initial chaining word from a runtime domain tag and `n`.<br />Both values must fit in a u32. The caller is responsible for registry and schema validation.<br /><br />Input:  [n, domain_tag, ...]<br />Output: [CV, ...]<br /><br />Invocation: exec<br /> |
| init_with_chaining_word | Adds two zero block words above a caller-supplied chaining word.<br /><br />Input:  [CV, ...]<br />Output: [BLOCK_LO=0w, BLOCK_HI=0w, CV, ...]<br /><br />Invocation: exec<br /> |
| init | Initializes a three-word state for a message under the generic Felt-sequence domain.<br />`num_elements` must fit in a u32.<br />An empty message still requires one zero-block compression after initialization.<br /><br />Input:  [num_elements, ...]<br />Output: [BLOCK_LO=0w, BLOCK_HI=0w, CV, ...]<br /><br />Invocation: exec<br /> |
| init_in_domain | Initializes a three-word state for a message under a runtime domain tag.<br />`num_elements` and the tag must fit in a u32.<br />An empty message still requires one zero-block compression after initialization.<br /><br />Input:  [num_elements, domain, ...]<br />Output: [BLOCK_LO=0w, BLOCK_HI=0w, CV, ...]<br /><br />Invocation: exec<br /> |
| compress | Performs one Eidos compression.<br /><br />Input:  [BLOCK_LO, BLOCK_HI, CV, ...]<br />Output: [BLOCK_LO, BLOCK_HI, CV', ...]<br /><br />Invocation: exec<br /> |
| digest | Returns the current chaining word from a three-word state by dropping the two block words.<br /><br />The returned word is a final digest only after the framed Eidos schedule is complete.<br /><br />Input:  [BLOCK_LO, BLOCK_HI, CV, ...]<br />Output: [CV, ...]<br /><br />Invocation: exec<br /> |
| copy_digest | Copies the current chaining word to the top of the stack.<br /><br />It is expected to have the hasher state at the top of the stack at the beginning of the procedure<br />execution. The copied word is a final digest only after the framed Eidos schedule is complete.<br /><br />Input: [BLOCK_LO, BLOCK_HI, CV, ...]<br />Output: [CV_COPY, BLOCK_LO, BLOCK_HI, CV, ...]<br /><br />Where:<br />- `BLOCK_LO` is the first preserved block word (positions 0-3, on top of stack).<br />- `BLOCK_HI` is the second preserved block word (positions 4-7).<br />- `CV` is the current chaining word (positions 8-11).<br />- `CV_COPY` is a copy of `CV`.<br /><br />Invocation: exec<br /> |
| absorb_double_words_from_memory | Absorbs complete 8-Felt blocks from `[start_addr, end_addr)` into the supplied state.<br /><br />An empty range preserves the state. A non-empty range may end at 2^32, immediately after<br />the last memory address.<br /><br />Input: [BLOCK_LO, BLOCK_HI, CV, start_addr, end_addr, ...]<br />Output: [BLOCK_LO', BLOCK_HI', CV', start_addr', end_addr, ...]<br />where `start_addr' = end_addr`.<br /><br />Where:<br />- `BLOCK_LO` is the first preserved block word (positions 0-3, on top of stack).<br />- `BLOCK_HI` is the second preserved block word (positions 4-7).<br />- `CV` is the current chaining word (positions 8-11).<br /><br />Panics if:<br />- `start_addr` is not a word-aligned u32 address.<br />- `end_addr < start_addr` or `end_addr > 2^32`.<br />- the range length is not a multiple of eight.<br /><br />Invocation: exec<br /> |
| hash_double_words | Hashes a memory range containing zero or more complete 8-Felt blocks.<br /><br />The range length must be a multiple of 8. The input length is bound into the initial chaining<br />word.<br /><br />Input: [start_addr, end_addr, ...]<br />Output: [HASH, ...]<br /><br />Invocation: exec<br /> |
| hash_words_with_domain | Hashes the word-aligned memory range `[start_addr, end_addr)` with a runtime domain tag.<br /><br />Requires `start_addr <= end_addr`, `end_addr` is not inclusive.<br />Requires `start_addr` and `end_addr` to be word-aligned.<br /><br />Input: [domain_tag, start_addr, end_addr, ...]<br />Output: [H, ...]<br /><br />Invocation: exec<br /> |
| hash_words | Hashes the word-aligned memory range `[start_addr, end_addr)`.<br /><br />Uses the generic Felt-sequence domain.<br /><br />Requires `start_addr <= end_addr`, `end_addr` is not inclusive.<br />Requires `start_addr` and `end_addr` to be word-aligned.<br /><br />Input: [start_addr, end_addr, ...]<br />Output: [H, ...]<br /><br />Invocation: exec<br /> |
| prepare_hasher_state | Initializes the state required by `hash_elements_with_state`.<br /><br />If `pad_inputs_flag` is zero, the initial chaining word binds `num_elements`. If the flag is<br />one, it binds `ceil(num_elements / 8) * 8`. Unused lanes of the final block are replaced with<br />zeros, so their memory contents are not committed.<br /><br />Input:  [ptr, num_elements, pad_inputs_flag, ...]<br />Output: [BLOCK_LO=0w, BLOCK_HI=0w, CV, ptr, end_pairs_addr, num_elements%8, ...]<br /><br />`ptr` must be word-aligned, `num_elements` must fit in a u32, and `pad_inputs_flag` must be zero<br />or one. Padded-length overflow is rejected.<br />For an empty input, the prepared CV already includes the required zero-block compression.<br /><br />Invocation: exec<br /> |
| hash_elements_with_state | Completes an Eidos stream with complete blocks and an optional partial block from memory.<br /><br />For a framed hash, the caller must initialize the stream with the correct domain and total<br />length. An empty continuation returns the supplied chaining word unchanged. Unused tail elements<br />are read from memory but replaced with zeros before compression.<br /><br />Inputs:  [BLOCK_LO, BLOCK_HI, CV, ptr, end_pairs_addr, remainder]<br />Outputs: [HASH]<br /><br />Where:<br />- `BLOCK_LO` and `BLOCK_HI` are block words; `CV` is the current chaining word.<br />- `[ptr, end_pairs_addr)` contains the complete blocks and must satisfy the range<br />requirements of `absorb_double_words_from_memory`.<br />- `remainder` is the number of elements in the partial block at `end_pairs_addr`, from 0 to 7.<br />- `HASH` is the final chaining word.<br /><br />Panics if the complete-block range is invalid, `remainder` exceeds seven, or a non-empty<br />tail's 8-Felt memory read would exceed the u32 address space.<br /><br />Invocation: exec<br /> |
| hash_elements_in_domain | Computes a domain-tagged hash of Felt values starting at the specified memory address.<br /><br />This procedure divides the hashing process into two parts: hashing pairs of words using<br />`absorb_double_words_from_memory` procedure and hashing the remaining values with `compress`<br />procedure.<br /><br />Inputs:  [ptr, num_elements, domain]<br />Outputs: [HASH]<br /><br />Where:<br />- ptr is the memory address of the first element to be hashed. This address must be<br />word-aligned - i.e., divisible by 4.<br />- num_elements is the number of elements to be hashed and must fit in a u32.<br />- domain is the runtime domain tag mixed into the initial chaining word.<br />- HASH is the resulting hash of the provided memory values.<br /><br />Invocation: exec<br /> |
| hash_elements | Hashes Felt values starting at the specified memory address under the generic Felt-sequence<br />domain.<br /><br />Input:  [ptr, num_elements, ...]<br />Output: [HASH, ...]<br /><br />`ptr` must be word-aligned, and `num_elements` must fit in a u32.<br /><br />Invocation: exec<br /> |
| pad_and_hash_elements | Hashes Felt values after padding the logical input length to a full 8-Felt block.<br /><br />This is not a hasher-internal padding rule. It changes the committed stream from<br />`elements[..num_elements]` to `elements[..padded_len]`, where<br />`padded_len = ceil(num_elements / 8) * 8`. The padding zeros are synthesized by this helper;<br />callers do not need to store them in memory. An empty sequence uses the canonical Eidos<br />empty-message path, including its required zero-block compression.<br /><br />Inputs:  [ptr, num_elements]<br />Outputs: [HASH]<br /><br />Where:<br />- ptr is the memory address of the first element to be hashed. This address must be<br />word-aligned - i.e., divisible by 4.<br />- num_elements is the number of elements to be hashed and must fit in a u32.<br />- HASH is the resulting hash of the provided memory values.<br /><br />Invocation: exec<br /> |
| hash | Computes the VM-native hash of a single word (256-bit input).<br /><br />Inputs:  [A]<br />Outputs: [B]<br /><br />Where:<br />- A is the word to be hashed.<br />- B is the resulting hash.<br /><br />Invocation: exec<br /> |
| hash_two_words | Hashes two words as an eight-Felt sequence under the generic Felt-sequence domain.<br /><br />Inputs:  [A, B]<br />Outputs: [C]<br /><br />Where:<br />- A and B are the words to be merged.<br />- C is the resulting hash.<br /><br />Invocation: exec<br /> |
| merge_with_chaining_word | Merges two words using a caller-supplied chaining word for their single 8-Felt block.<br /><br />Inputs:  [CV, A, B, ...]<br />Outputs: [C, ...]<br /><br />Invocation: exec<br /> |
| hash_two_words_in_domain | Hashes two words as an eight-Felt sequence under a runtime domain tag.<br /><br />Inputs:  [domain, A, B, ...]<br />Outputs: [C, ...]<br /><br />Where:<br />- A and B are the words to be merged (A is the first block word).<br />- C is `hash_elements_in_domain(A \|\| B, domain)`.<br /><br />Invocation: exec<br /> |
