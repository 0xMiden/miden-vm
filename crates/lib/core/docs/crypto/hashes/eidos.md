
## miden::core::crypto::hashes::eidos
| Procedure | Description |
| ----------- | ------------- |
| init_chaining_word_with_params | Constructs an Eidos chaining word from a registered selector and three selector-defined<br />parameters. Every input must fit in a u32. Each occupies the low lane of one packed Felt; the<br />corresponding high lane is a fixed masked IV word.<br /><br />Input:  [selector, param0, param1, param2, ...]<br />Output: [CV, ...]<br /><br />Invocation: exec<br /> |
| empty_felt_sequence_digest | Returns the Eidos digest of an empty Felt sequence under selector zero.<br /><br />Input:  [...]<br />Output: [DIGEST, ...]<br /><br />Invocation: exec<br /> |
| init_chaining_word | Constructs `Eidos::init_chaining_word(0, n)`.<br />`n` must fit in a u32.<br /><br />Input:  [n, ...]<br />Output: [CV, ...]<br /><br />Invocation: exec<br /> |
| init_chaining_word_in_domain | Constructs `Eidos::init_chaining_word(selector, n)`.<br />`n` and `selector` must fit in a u32.<br /><br />Input:  [n, selector, ...]<br />Output: [CV, ...]<br /><br />Invocation: exec<br /> |
| init_with_chaining_word | Adds two zero block words above a caller-supplied chaining word.<br /><br />Input:  [CV, ...]<br />Output: [BLOCK_LO=0w, BLOCK_HI=0w, CV, ...]<br /><br />Invocation: exec<br /> |
| init | Initializes a three-word state for a message of `num_elements` Felts in domain zero.<br />`num_elements` must fit in a u32.<br />An empty message still requires one zero-block compression after initialization.<br /><br />Input:  [num_elements, ...]<br />Output: [BLOCK_LO=0w, BLOCK_HI=0w, CV, ...]<br /><br />Invocation: exec<br /> |
| init_in_domain | Initializes a three-word state for a message of `num_elements` Felts in the given domain.<br />`num_elements` and `domain` must fit in a u32.<br />An empty message still requires one zero-block compression after initialization.<br /><br />Input:  [num_elements, domain, ...]<br />Output: [BLOCK_LO=0w, BLOCK_HI=0w, CV, ...]<br /><br />Invocation: exec<br /> |
| compress | Performs one Eidos compression.<br /><br />Input:  [BLOCK_LO, BLOCK_HI, CV, ...]<br />Output: [BLOCK_LO, BLOCK_HI, CV', ...]<br /><br />Invocation: exec<br /> |
| digest | Returns the current chaining word from a three-word state by dropping the two block words.<br /><br />The returned word is a final digest only after the framed Eidos schedule is complete.<br /><br />Input:  [BLOCK_LO, BLOCK_HI, CV, ...]<br />Output: [CV, ...]<br /><br />Invocation: exec<br /> |
| copy_digest | Copies the current chaining word to the top of the stack.<br /><br />It is expected to have the hasher state at the top of the stack at the beginning of the procedure<br />execution. The copied word is a final digest only after the framed Eidos schedule is complete.<br /><br />Input: [BLOCK_LO, BLOCK_HI, CV, ...]<br />Output: [CV_COPY, BLOCK_LO, BLOCK_HI, CV, ...]<br /><br />Where:<br />- `BLOCK_LO` is the first preserved block word (positions 0-3, on top of stack).<br />- `BLOCK_HI` is the second preserved block word (positions 4-7).<br />- `CV` is the current chaining word (positions 8-11).<br />- `CV_COPY` is a copy of `CV`.<br /><br />Invocation: exec<br /> |
| absorb_double_words_from_memory | Hashes the memory `start_addr` to `end_addr` given a three-word VM hasher state.<br /><br />This requires that `end_addr = start_addr + 8n` where n = {0, 1, 2 ...}, otherwise the procedure<br />will enter an infinite loop.<br /><br />Input: [BLOCK_LO, BLOCK_HI, CV, start_addr, end_addr, ...]<br />Output: [BLOCK_LO', BLOCK_HI', CV', start_addr', end_addr, ...]<br />where `start_addr' = end_addr`.<br /><br />Where:<br />- `BLOCK_LO` is the first preserved block word (positions 0-3, on top of stack).<br />- `BLOCK_HI` is the second preserved block word (positions 4-7).<br />- `CV` is the current chaining word (positions 8-11).<br /><br />Invocation: exec<br /> |
| hash_double_words | Hashes a memory range containing zero or more complete 8-Felt blocks.<br /><br />The range length must be a multiple of 8. The input length is bound into the initial chaining<br />word.<br /><br />Input: [start_addr, end_addr, ...]<br />Output: [HASH, ...]<br /><br />Invocation: exec<br /> |
| hash_words_with_domain | Hashes the word-aligned memory range `[start_addr, end_addr)` with a domain identifier.<br /><br />Requires `start_addr <= end_addr`, `end_addr` is not inclusive.<br />Requires `start_addr` and `end_addr` to be word-aligned.<br /><br />Input: [domain, start_addr, end_addr, ...]<br />Output: [H, ...]<br /><br />Invocation: exec<br /> |
| hash_words | Hashes the word-aligned memory range `[start_addr, end_addr)`.<br /><br />Equivalent to `hash_words_with_domain` with `domain = 0`.<br /><br />Requires `start_addr <= end_addr`, `end_addr` is not inclusive.<br />Requires `start_addr` and `end_addr` to be word-aligned.<br /><br />Input: [start_addr, end_addr, ...]<br />Output: [H, ...]<br /><br />Invocation: exec<br /> |
| prepare_hasher_state | Initializes the state required by `hash_elements_with_state`.<br /><br />If `pad_inputs_flag` is zero, the initial chaining word binds `num_elements`. If the flag is<br />one, it binds `ceil(num_elements / 8) * 8`. Unused lanes of the final block are replaced with<br />zeros, so their memory contents are not committed.<br /><br />Input:  [ptr, num_elements, pad_inputs_flag, ...]<br />Output: [BLOCK_LO=0w, BLOCK_HI=0w, CV, ptr, end_pairs_addr, num_elements%8, ...]<br /><br />`ptr` must be word-aligned, `num_elements` must fit in a u32, and `pad_inputs_flag` must be zero<br />or one. Padded-length overflow is rejected.<br />For an empty input, the prepared CV already includes the required zero-block compression.<br /><br />Invocation: exec<br /> |
| hash_elements_with_state | Computes hash of Felt values starting at the specified memory address using the provided hasher<br />state.<br /><br />This procedure divides the hashing process into two parts: hashing pairs of words using<br />`absorb_double_words_from_memory` procedure and hashing the remaining values with `compress`<br />procedure.<br />An empty continuation returns the supplied chaining word unchanged.<br /><br />Inputs:  [BLOCK_LO, BLOCK_HI, CV, ptr, end_pairs_addr, num_elements%8]<br />Outputs: [HASH]<br /><br />Where:<br />- ptr is the memory address of the first element to be hashed. This address must be<br />word-aligned - i.e., divisible by 4.<br />- BLOCK_LO and BLOCK_HI are block words, and CV is the current chaining word.<br />- end_pairs_addr is the memory address at which the pairs of words end.<br />- num_elements%8 is the number of elements that did not fit into word pairs and should be<br />hashed separately.<br />- HASH is the resulting hash of the provided memory values.<br /><br />Invocation: exec<br /> |
| hash_elements_in_domain | Computes a domain-tagged hash of Felt values starting at the specified memory address.<br /><br />This procedure divides the hashing process into two parts: hashing pairs of words using<br />`absorb_double_words_from_memory` procedure and hashing the remaining values with `compress`<br />procedure.<br /><br />Inputs:  [ptr, num_elements, domain]<br />Outputs: [HASH]<br /><br />Where:<br />- ptr is the memory address of the first element to be hashed. This address must be<br />word-aligned - i.e., divisible by 4.<br />- num_elements is the number of elements to be hashed and must fit in a u32.<br />- domain is the domain identifier mixed into the initial chaining word.<br />- HASH is the resulting hash of the provided memory values.<br /><br />Invocation: exec<br /> |
| hash_elements | Hashes Felt values starting at the specified memory address in domain zero.<br /><br />Input:  [ptr, num_elements, ...]<br />Output: [HASH, ...]<br /><br />`ptr` must be word-aligned, and `num_elements` must fit in a u32.<br /><br />Invocation: exec<br /> |
| pad_and_hash_elements | Hashes Felt values after padding the logical input length to a full 8-Felt block.<br /><br />This is not a hasher-internal padding rule. It changes the committed stream from<br />`elements[..num_elements]` to `elements[..padded_len]`, where<br />`padded_len = ceil(num_elements / 8) * 8`. The padding zeros are synthesized by this helper;<br />callers do not need to store them in memory. An empty sequence uses the canonical Eidos<br />empty-message path, including its required zero-block compression.<br /><br />Inputs:  [ptr, num_elements]<br />Outputs: [HASH]<br /><br />Where:<br />- ptr is the memory address of the first element to be hashed. This address must be<br />word-aligned - i.e., divisible by 4.<br />- num_elements is the number of elements to be hashed and must fit in a u32.<br />- HASH is the resulting hash of the provided memory values.<br /><br />Invocation: exec<br /> |
| hash | Computes the VM-native hash of a single word (256-bit input).<br /><br />Inputs:  [A]<br />Outputs: [B]<br /><br />Where:<br />- A is the word to be hashed.<br />- B is the resulting hash.<br /><br />Invocation: exec<br /> |
| merge | Merges two words (256-bit digests) via the VM-native hash.<br /><br />Inputs:  [A, B]<br />Outputs: [C]<br /><br />Where:<br />- A and B are the words to be merged.<br />- C is the resulting hash.<br /><br />Invocation: exec<br /> |
| merge_with_chaining_word | Merges two words using a caller-supplied chaining word for their single 8-Felt block.<br /><br />Inputs:  [CV, A, B, ...]<br />Outputs: [C, ...]<br /><br />Invocation: exec<br /> |
| merge_in_domain | Merges two words (256-bit digests) via the VM-native hash with a domain identifier.<br /><br />Inputs:  [domain, A, B, ...]<br />Outputs: [C, ...]<br /><br />Where:<br />- A and B are the words to be merged (A is the first block word).<br />- C is `hash_elements_in_domain(A \|\| B, domain)`.<br /><br />Invocation: exec<br /> |
