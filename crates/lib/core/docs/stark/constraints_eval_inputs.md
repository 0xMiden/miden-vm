
## miden::core::stark::constraints_eval_inputs
| Procedure | Description |
| ----------- | ------------- |
| set_up_auxiliary_inputs_ace | Sets up the multi-AIR ACE input layout shared by relation verifiers.<br /><br />The stark-vars block starts with 10 EF slots:<br /><br />Word 0 (slots 0-1): alpha, z^N<br />Word 1 (slots 2-3): z_k, is_first<br />Word 2 (slots 4-5): is_last, is_transition<br />Word 3 (slots 6-7): reserved, weight0<br />Word 4 (slots 8-9): f, s0<br /><br />The global selector slots in words 1-2 are unused by multi-AIR circuits. The per-AIR<br />selectors start at slot 10: AIR k occupies slots 10 + 3k through 12 + 3k.<br /><br />The per-AIR fold coefficients that follow the selectors are staged by each relation's generated<br />evaluator (`stage_air_fold_coefficients` in `sys/<relation>/constraints_eval.masm`) from the<br />proof-order maps, after this procedure has run.<br /><br />`heights_ptr` addresses the relation's `num_airs` consecutive per-AIR log-height<br />cells; AIR k's selectors are derived from the height at `heights_ptr + k`.<br />`proof_order_ids_ptr` addresses a permutation of those AIR indices sorted by increasing height.<br />The relation must compute this map from its validated heights before calling this procedure.<br />Heights and `max_cycle_len_log` must not exceed the maximum height stored at<br />`LOG_TRACE_LENGTH_PTR`. Reverse proof order lets the lifted OOD point and inverse domain<br />generator advance by squaring, while selectors are stored in canonical order.<br /><br />`stark_vars_ptr` is the relation's stark-vars base. The ACE READ section is one dense<br />vector whose region spacing must equal the relation's circuit layout spacing, so this<br />base is relation-local rather than a shared constant.<br />The output region must be disjoint from both input arrays and the shared domain state.<br /><br />For quotient arity D and maximum trace length N, the relation supplies<br />quot_first_shift = s0 = shift^N, quot_shift_ratio (a primitive D-th root of unity), and<br />quot_first_weight = 1 / (D * s0^(D-1)). D and the LDE blowup are separate protocol parameters.<br /><br />Input:  [max_cycle_len_log, num_airs, heights_ptr, stark_vars_ptr, quot_first_weight,<br />quot_first_shift, quot_shift_ratio, proof_order_ids_ptr, ...]<br />Output: [...]<br /> |
