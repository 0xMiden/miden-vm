
## miden::core::stark::public_inputs
| Procedure | Description |
| ----------- | ------------- |
| process_public_inputs | Processes the public inputs.<br /><br />This generic procedure dispatches to the relation-specific public-input handler via `dynexec`.<br />The relation handler owns its public-input schema and Fiat-Shamir observation schedule.<br /><br />Inputs:  [...]<br />Outputs: [...]<br /><br />Invocation: exec<br /> |
| compute_and_store_public_inputs_address | Computes and stores the start address of the ACE public-input region.<br /><br />The public-input region stores `num_fixed_len_pi` base-field public values as extension-field<br />slots, i.e. two base-field memory cells per public value. It is placed immediately before the<br />aux-randomness word in ACE READ.<br /><br />This helper only computes the ACE READ public-input pointer. Relation-specific code owns any<br />additional statement inputs that are not read by the ACE circuit.<br /><br />Inputs:  [aux_rand_ptr, num_fixed_len_pi, ...]<br />Outputs: [...]<br /><br />Invocation: exec<br /> |
| load_base_store_extension_double_word_from_mem | Loads 8 base-field elements from memory, stores them as 8 extension-field elements, and leaves<br />the base elements in the block slots for one complete Eidos compression.<br /><br />The caller is responsible for absorbing the returned block into its transcript.<br /><br />Both pointers must be word-aligned. The source and destination ranges must be disjoint from<br />one another and from the words at `TMP1_PTR`, `TMP2_PTR`, and `ZERO_WORD_PTR`.<br />The first two words are overwritten as scratch; the zero word must contain four zeros.<br /><br />Inputs:  [BLOCK_LO, BLOCK_HI, CV, dst, src, ...]<br />Outputs: [A0, A1, CV, dst + 16, src + 8, ...]<br /><br />A0 and A1 are the original base-element words from memory, in increasing address order.<br /><br />Invocation: exec<br /> |
| copy_base_to_extension_double_word | Copies 8 base-field elements from `src` to 8 extension-field slots at `dst`.<br />Each output slot contains the source element followed by a zero high coordinate.<br /><br />Both pointers must be word-aligned. The word at `ZERO_WORD_PTR` must contain four zeros,<br />and the destination must not overlap it. All 8 source elements are read before any write.<br />The three scratch words may contain arbitrary values and are overwritten.<br /><br />Inputs:  [scratch(12), src, dst, ...]<br />Outputs: [scratch(12), src + 8, dst + 16, ...]<br /><br />Invocation: exec<br /> |
