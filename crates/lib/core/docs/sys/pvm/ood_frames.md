
## miden::core::sys::pvm::ood_frames
| Procedure | Description |
| ----------- | ------------- |
| stage_ood_scatter_table | Stages the proof-order-dependent half of the out-of-domain scatter table.<br /><br />The proof commits each chiplet's trace at its position in the height-sorted proof order, while<br />the canonical constraint circuit reads it at the chiplet's instance offset. Both the canonical<br />destination and the segment length are compile-time per chiplet; this procedure only routes them<br />to the stream position the absorbed trace heights put that chiplet in.<br /><br />Must run after the AIR heights are stored and before the first out-of-domain row is ingested.<br /><br />Inputs:  []<br />Outputs: []<br /> |
| process_row_ood_evaluations | Processes one PVM row of out-of-domain evaluations, scattering it to canonical addresses.<br /><br />The row is the LMCS-aligned wire sequence used by the lifted PCS, in commitment-group order:<br /><br />- 8 preprocessed extension-field slots;<br />- 528 main extension-field slots across 10 chiplets in proof order;<br />- 280 auxiliary-coordinate extension-field slots across 10 chiplets in proof order;<br />- 8 quotient extension-field slots.<br /><br />Each block is stored, folded into the DEEP fixed term with `horner_eval_ext`, and compressed<br />into the Eidos transcript. The absorb and the accumulation stay positional over the advice<br />stream; the only thing the proof order moves is where each segment is stored, which the table<br />staged by `stage_ood_scatter_table` supplies.<br /><br />Inputs:  [scratch0, scratch1, cv, ptr, alpha_ptr, acc0, acc1]<br />Outputs: [scratch0, scratch1, cv', ptr + 1648, alpha_ptr, acc0', acc1']<br /> |
