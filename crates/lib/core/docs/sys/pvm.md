## miden::core::sys::pvm
| Procedure | Description |
| ----------- | ------------- |
| load_air_context | Validate canonical AIR heights, then stage permutation maps, scatter and context pointers.<br /> |
| request_proof | Fetch root-bound advice; the response remains untrusted until verification.<br /> |
| verify_proof | Check the hash AIR mask and verify with the selected trusted relation.<br /> |
| verify_selected_proof | Reserve the call window for the full ALL relation.<br /> |

The advice stream begins with a checked three-bit hash mask (Keccak=1, SHA-256=2, SHA-512=4),
then the four security parameters, selected canonical log heights and proof data. The single public
verifier dispatches to trusted generated wrappers/parameters under `v0` through `v6`, or the full relation for mask7.
The algorithms execute once-shared `sys::verifier` runtime kernels.
Each route pins its own ACE/transcript identity and security shape. Native ALL payloads preserve
their historical encoding; reduced native framing is decoded by the host adapter before advice
construction. Variant selection and consolidated runtime sharing change the recursive PVM root, independently
of native ALL compatibility. Current execution envelopes support only the newly derived roots.
