Top-level module for internal MASM precompile support.<br /><br />Concrete precompile support modules live here and in submodules. The helper procedures in this<br />module are shared by generated and hand-written wrappers.<br />


## miden::core::precompiles
| Procedure | Description |
| ----------- | ------------- |
| word_eq | Returns whether two words are equal, consuming both words.<br /><br />This helper keeps generated precompile modules independent of `miden-core`. Importing<br />`miden::core::word::eq` here would create a dependency cycle because `miden-core` dynamically<br />depends on `miden-precompiles`.<br /><br />Inputs:  [RHS, LHS]<br />Outputs: [is_equal]<br /><br />Where:<br />- RHS is the first word to compare.<br />- LHS is the second word to compare.<br />- is_equal is one if the words are equal, and zero otherwise.<br /><br />Invocation: exec<br /> |
| register_fixed_expr | Registers a fixed one-block expression using a caller-supplied initial chaining word.<br /><br />The host recovers the unique frame encoded by `CV`; the VM uses the same `CV` to hash the<br />payload. This keeps registration metadata and digest framing identical by construction.<br /><br />Input:  [CV, PAYLOAD_LO, PAYLOAD_HI, ...]<br />Output: [NODE_DIGEST, ...]<br /> |
| register_expr | Registers an expression-bodied node `(frame, payload)` in the deferred-computation DAG and returns<br />its content-addressed digest on top of the operand stack.<br /><br />Input:  [FRAME=[domain_tag, param0, param1, param2], PAYLOAD_LO, PAYLOAD_HI, ...]<br />Output: [NODE_DIGEST, ...]<br /> |
| register_mem | Registers a data-bodied node (`n` eight-Felt blocks of bulk data at `ptr`) in the<br />deferred-computation DAG and returns its content-addressed digest on top of the operand stack.<br /><br />`adv.register_deferred_data` interns the node host-side by reading `8n` felts from memory at<br />`ptr`, where `n` is the stack-supplied `n_chunks`; it produces no stack or advice output. The<br />event leaves those stack arguments unchanged, but its direct host read adds no AIR memory access.<br />`CV` must be a framed Eidos initial chaining word, `n_chunks` must be a nonzero `u32`, and the<br />frame's payload grammar must admit exactly `n_chunks` blocks. The event validates those recovered<br />values before the hashing loop begins. The caller remains responsible for checking every dynamic<br />input as a `u32` before injecting it into `CV`.<br />This wrapper binds the registration input with the same Eidos construction as `Node::digest`:<br />the supplied initial chaining word is followed by the `n` payload chunks. Empty data bodies are<br />forbidden, so `n >= 1`.<br /><br />Input:  [CV, ptr, n_chunks, ...]<br />Output: [NODE_DIGEST, ...]<br /> |
| register_chunks_mem | Registers memory as framework CHUNKS data and returns its content-addressed digest.<br /><br />Input:  [ptr, n_chunks, ...]<br />Output: [CHUNKS_DIGEST, ...]<br /> |
| register_chunks_mem_1 | Registers exactly one 8-felt memory chunk as framework CHUNKS data.<br /><br />Input:  [ptr, ...]<br />Output: [CHUNKS_DIGEST, ...]<br /> |
| register_chunks_mem_2 | Registers exactly two contiguous 8-felt memory chunks as framework CHUNKS data.<br /><br />Input:  [ptr, ...]<br />Output: [CHUNKS_DIGEST, ...]<br /> |
| register_chunks_mem_3 | Registers exactly three contiguous 8-felt memory chunks as framework CHUNKS data.<br /><br />Input:  [ptr, ...]<br />Output: [CHUNKS_DIGEST, ...]<br /> |
| log_deferred | Folds a deferred node digest into the rolling deferred root using `log_deferred`.<br />The digest must reference a node that will reduce to TRUE under the installed precompiles.<br /><br />The opcode replaces NODE_DIGEST with the updated deferred root, which this helper drops.<br /><br />Input:  [NODE_DIGEST, ...]<br />Output: `[...]` (the deferred commitment root advances; node is folded in)<br /> |
